From circuits to the cloud

This portfolio records our work in WSU-COS 209 The Circuit-to-Cloud Workshop: twelve practicals that start with logic gates on a breadboard and end with an ESP32 sending sensor readings to our own web server.

Practicals

  • P1 Number systems

    Binary, hex, BCD, Gray code and two's complement, with a live converter.

    Uno + web

  • P2 Logic gates

    Testing 74HC00/08/32/86 gates and recording truth tables.

    Uno

  • P3 Karnaugh maps

    Simplifying a prime-digit detector and building it from NAND gates.

    Uno

  • P4 Adders & comparators

    Exhaustive tests of the 74HC283 and 74HC85.

    Uno + web

  • P5 Decoders & displays

    74HC138, 74HC151 and a 7-segment counter.

    Uno

  • P6 Latches & flip-flops

    Switch bounce, an SR latch and the 74HC74 D flip-flop.

    Uno + web

  • P7 Counters & registers

    74HC161 counter, 74HC595 LED patterns and a tri-state bus.

    Uno + web

  • P8 State machines

    A pedestrian crossing as a non-blocking finite state machine.

    Uno + web

  • P9 Sensors & Web Serial

    A light sensor streamed as JSON into a browser dashboard.

    Uno + web

  • P10 ESP32 web server

    Controlling an LED from a phone over Wi-Fi.

    ESP32

  • P11 A REST API

    JSON endpoints and a polling dashboard on the ESP32.

    ESP32

  • P12 Cloud logger

    Posting readings to our own Flask or Node server and database.

    ESP32 + server
