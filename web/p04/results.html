Why does this page not work when I double-click it?

If you open the file directly, the address bar starts with file://. For security, browsers do not let a page loaded from file:// use fetch() to read other files on your disk (otherwise any downloaded web page could read your documents).

Serve the folder over HTTP instead. From the repository root run python tools/serve.py web and open http://127.0.0.1:8000/p04/results.html.
